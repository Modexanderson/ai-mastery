## Common Tech Stack

All apps share:
- **Frontend:** Flutter 3.x (iOS + Android + Desktop where applicable)
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL + Firebase
- **AI:** Claude API + on-device models (ONNX/TFLite) + custom PyTorch models
- **State Management:** Riverpod
- **Architecture:** Clean Architecture (data/domain/presentation layers)
- **Web Dashboards:** React + TypeScript (where applicable)

## How to Continue

Each project folder contains a `BLUEPRINT.md` with:
- Complete branding (name, tagline, colors, logo concept)
- Problem statement and market context
- Detailed feature specifications with AI output examples
- Tech stack details and dependencies
- File structure with every file planned
- AI/ML model details and training approaches
- Development phases broken into weekly sprints
- Monetization strategy with pricing tiers

To start any project:
1. Read the BLUEPRINT.md thoroughly
2. Follow Phase 1 week-by-week
3. Set up Flutter project with the specified architecture
4. Build features in the order listed
5. Each phase builds on the previous one
6. All projects can share backend patterns (FastAPI + PostgreSQL + Firebase auth)
